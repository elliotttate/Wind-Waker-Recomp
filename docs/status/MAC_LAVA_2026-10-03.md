# Mac lava: the Windows post-transform fix

The latest Windows branch inspected was Wind-Waker-Recomp `13355b8`. Its lava
fix landed in `cde4df7`, importing RecompCore `81d7345` (test line endings fixed
in `7c62903`). Ported that renderer change to the Mac's pinned RecompCore
`8ab24da`, retaining the existing water interpolation delta and Forest Water
options.

GX applies a second, post-transform matrix to the lava's crust texture and its
height-dependent colour ramp. The renderer previously ignored those matrices,
making the lava white or flat orange. The frontend now records the matrices
outside its serialized state and carries them with each draw; gxcore combines
them with the ordinary texture matrix. This preserves the saved frontend
layout and shader/pipeline cache format. Normalizing post transforms are still
unsupported, as in the Windows fix; Wind Waker's lava does not use them.

The checked-in `0120` patch records the imported Windows change. The full Mac
delta is `0130-mac-water-interpolation-and-lava-post-transforms.patch`, selected
and checksummed by `config/recompcore-patches.json`. Its base dependency pin is
unchanged. The host, builder and iOS CMake paths share that manifest.

Validation used the player's current checkpoint in Fire Mountain's interior,
`MiniKaz`, with the configured HD texture pack, 16x filtering and 120-Hz Smooth
Motion. Private test runs used copies of the memory card and checkpoint, with
only the copied checkpoint's live-input takeover disabled for a scripted menu
close. The original checkpoint was untouched.

- Before: the lava surface drew white.
- After: the same camera shows orange/yellow lava with dark crust.
- Both native runs loaded the existing state successfully, retained identical
  inventory and watered-tree bits, and advanced Forest Water by the same ticks.
- `gxcore_tests` (including the imported ST/STQ post-matrix fold test),
  `aurora_recomp_frontend_tests`, the water interpolation test, Forest Water
  option guards and runtime patch application tests passed.

Private captures, logs, state copies and app backups are under
`build/wwhd-playtest/lava-mac/`; they are not release assets.

The HUD follow-up selects combined delta `0170` in the same manifest, retaining
this lava fix and the water fix while restoring smooth screen-space animation
with local sprite matching. See `MAC_HUD_INTERPOLATION_2026-10-03.md`.
